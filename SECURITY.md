# Zgłaszanie problemów bezpieczeństwa

Nie zgłaszaj podatności w publicznym issue ani w publicznym Pull Requeście. Zamiast tego użyj prywatnego zgłoszenia bezpieczeństwa GitHuba:

1. Otwórz kartę **Security** w repozytorium.
2. Wybierz **Advisories**, a następnie **Report a vulnerability**.
3. Opisz problem i kroki potrzebne do jego odtworzenia bez podawania prawdziwych haseł, danych uczniów ani danych szkolnych.

Zgłoszenie trafi prywatnie do opiekunów repozytorium, którzy mogą skontaktować się z Tobą przez GitHub w celu wyjaśnienia szczegółów. Nie wysyłaj w zgłoszeniu danych logowania do Librusa ani prawdziwych danych z dziennika. Jeśli prywatne zgłoszenia nie są dostępne, skontaktuj się z opiekunem repozytorium prywatnie na GitHubie; nie ujawniaj szczegółów publicznie.
